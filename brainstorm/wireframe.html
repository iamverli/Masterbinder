09 — Navigation Flow Summary
How screens connect. All primary navigation from Home. Drawer accessible from any screen via avatar tap.
QR Scan → Landing → Home
Home · Avatar tap → Left Drawer (accessible from any screen)
Home · Pokédex card tap → National Pokédex → Card tile ⋮ → Card Selector → Card Detail
Home · FAB + → Set Selector (slides up) → Tap set → Set Tracker
Home · In Progress / Completed set tap → Set Tracker
Any screen · Share ⤴ → QR Share sheet
Drawer · Back to Login → Landing
Drawer · Version tap → System Log popup
